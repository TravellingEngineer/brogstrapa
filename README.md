## `bny-base`

Reference platform for validation of the [barney](https://github.com/barney-build/barney) tool.

This repository contains a base definition from which others can derive their own works to build
Linux based operating systems.

Explicitly this is **not** a general purpose operating system, it is instead a launchpad for others efforts.
Currently no effort is made towards stability until such point as `barney` stabilises, at which point I'll build
a proper process around this repository to allow derivative works in a streamlined fashion.
